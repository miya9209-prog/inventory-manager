# 재고 관제센터

셀러OS에 붙이기 위한 독립형 Streamlit 모듈입니다.

## 이번 버전 방향
- 구글드라이브 자동 연동 없음
- 셀메이트 API 없음
- 프로그램 안에서 셀메이트 재고 엑셀을 직접 업로드
- 업로드 버튼 클릭 시 셀메이트 재고 DB가 즉시 업데이트
- 판단 기준 재고는 셀메이트 실제재고
- 카페24는 상품/주문/판매상태/품절상태 감지용

## 운영 방식
1. 매일 오후 1~2시경 셀메이트에서 재고 엑셀을 다운로드합니다.
2. 재고 관제센터 상단의 `셀메이트 재고 DB 업데이트` 영역에서 엑셀을 업로드합니다.
3. 미리보기를 확인한 뒤 `셀메이트 재고 DB 업데이트` 버튼을 누릅니다.
4. 카페24 상품/주문 동기화를 실행합니다.
5. 오늘의 긴급 알림, 품절 위험, 입고 추천, 시즌 오픈 추천, 악성재고를 확인합니다.

## 셀메이트 엑셀 필수 컬럼
아래 이름 중 하나만 있으면 자동 인식합니다.

- 상품코드: 상품코드, 상품번호, 판매처상품코드, 자체상품코드, 품목코드
- 상품명: 상품명, 품목명, 제품명
- 옵션명: 옵션명, 옵션, 색상/사이즈
- 재고: 재고, 현재고, 실재고, 가용재고, 재고수량, 수량

## Streamlit Secrets
`.streamlit/secrets.toml.example` 참고

## 실행

```bash
pip install -r requirements.txt

```
