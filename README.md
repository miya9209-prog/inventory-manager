# 재고 관제센터

셀러OS에 붙이기 위한 독립형 Streamlit 모듈입니다.

## 핵심 변경
- 좌측 메뉴바 제거
- 제목: 재고 관제센터
- 셀메이트 API 대신 매일 오후 1~2시 수동 엑셀 업로드 방식
- 판단 기준 재고: 셀메이트 실제재고 우선
- 카페24 재고/품절/판매상태는 매출손실 감지용

## 운영 방식
1. 카페24 API로 상품/주문 데이터를 동기화합니다.
2. 매일 오후 1~2시경 셀메이트 재고 엑셀을 내려받아 업로드합니다.
3. 재고 관제센터는 셀메이트 실제재고를 기준으로 품절위험·입고추천·악성재고를 판단합니다.
4. 카페24 품절처리 상태와 셀메이트 실제재고가 다르면 긴급 알림으로 표시합니다.

## 셀메이트 엑셀 필수 컬럼
아래 이름 중 하나만 있으면 자동 인식합니다.
- 상품코드: 상품코드, 상품번호, 판매처상품코드, 자체상품코드, 품목코드
- 상품명: 상품명, 품목명, 제품명
- 옵션명: 옵션명, 옵션, 색상/사이즈
- 재고: 재고, 현재고, 실재고, 가용재고, 재고수량, 수량

## Streamlit Secrets
`.streamlit/secrets.toml.example` 참고

## 실행
```bash
pip install -r requirements.txt

```
